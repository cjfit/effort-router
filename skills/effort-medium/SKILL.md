# Medium effort

This is routine work with a clear scope. The frontmatter has set effort to
medium — proceed with the user's task directly, at normal thoroughness: read
what you need, make the change, verify it the ordinary way (run the obvious
test or check), and report briefly.

If the task turns out to touch several files or hides an unknown-cause bug,
note that it's bigger than it looked so the next task can route higher.
